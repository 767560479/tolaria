# Browse The File Tree And Tabs

Tolaria keeps multiple notes open as editor tabs and shows folders and Markdown files in the left sidebar file tree. Use both surfaces together when you want a files-first workflow instead of only Inbox or All Notes.

## File Tree

The Folders section in the sidebar lists vault folders and the Markdown notes inside them.

- Click a folder to focus that folder in the note list.
- Click a Markdown file to open it as an editor tab.
- Right-click a folder to create a note or subfolder, rename, delete, reveal the folder on disk, or copy its path.
- Right-click a note in the tree for the same actions available in the note list, including rename, delete, move to folder, and duplicate.

New notes created from a folder context menu are created inside that folder and open immediately for editing.

## Editor Tabs

Each open note becomes a tab above the editor.

- Click a tab to switch notes without closing the previous one.
- Click the tab close control to close one note.
- Right-click a tab to close it, close the others, or close all tabs.
- Unsaved edits show a dirty indicator on the tab. Closing other or all tabs asks for confirmation when those tabs still have unsaved edits.

Filenames stay visible in the breadcrumb so the on-disk file stays easy to recognize while tabs show the note title.

## Command Palette Shortcuts

These commands work from the command palette (`Cmd+K` / `Ctrl+K`):

- Duplicate Note.
- Close Other Tabs.
- Close All Tabs.
- Create New Note in Current Folder when a folder is selected.
